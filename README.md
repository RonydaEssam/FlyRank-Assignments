# FlyRank Internship — Backend AI Engineering Track

This repository collects the assignments completed during my backend internship at FlyRank. Each task lives in its own subfolder with its own README, setup instructions, and notes.

## About the internship

Remote, self-paced backend internship at FlyRank. Assignments build up backend and AI-engineering skills incrementally, starting from minimal servers and progressing toward more complex systems.

## Tech stack

Stack is not stricted by FlyRank, this is the stack I will be using.

- **Language:** TypeScript
- **Framework:** Express
- **Runtime:** Node.js
- **Dev tooling:** tsx, nodemon
